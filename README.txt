PREVIEW
1. Extract the ZIP file.
2. Open index.html in a browser.

PUBLISH FOR FREE
Option 1: GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a public repository, e.g. earnpath-site.
3. Upload index.html (and README.txt if desired) to the repository root.
4. Open repository Settings > Pages.
5. Select deploy from branch, choose main and / (root), then save.
6. Wait for GitHub Pages to publish the site and use the provided free URL.

Option 2: Another reputable static hosting provider's free tier.
Read the provider's current terms before publishing.
